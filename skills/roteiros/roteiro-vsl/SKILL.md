# roteiro-vsl — vender por vídeo, sem enganar

Base: `docs/conhecimento/10` §3, `08` §4. Depois: `video-vsl`.

## 1. Estrutura (com tempo para 5 min ≈ 750 palavras)

| Bloco | % do tempo | Conteúdo |
|---|---|---|
| Gancho | 5% | Promessa específica + para quem é; prova rápida |
| Problema e agitação | 15% | A dor com as palavras do público; o custo de não resolver |
| História / credibilidade | 15% | Quem fala e por que ouvir (fato verificável) |
| Mecanismo | 15% | Por que esta solução funciona (o "como" único) |
| Prova | 15% | Casos, números, demonstração — reais e autorizados |
| Oferta | 15% | O que a pessoa recebe, item a item, com valor |
| Preço e garantia | 10% | Preço, parcelamento, garantia real |
| Escassez e CTA | 10% | Prazo/vagas **reais**; o que fazer agora; repetir o CTA |

## 2. Escrita

- Frases curtas, uma ideia por frase; "você" mais que "nós".
- Releia em voz alta: ~150 palavras/min. Corte o que não move para a compra.
- Objeções respondidas onde aparecem (preço na oferta, tempo no mecanismo, medo na garantia).

## 3. Marcação de tela

Ao lado de cada parágrafo, o que se vê:

```
[A-ROLL] rosto · [SLIDE] título do slide (≤ 7 palavras) · [B-ROLL] imagem concreta
[LT] lower third (nome, cargo) · [NÚMERO] dado em destaque · [CTA] botão/endereço na tela
```

Slides e números viram `.mogrt` (`motion-graficos-de-video`); legenda sempre.

## 4. Cortes derivados (planeje junto)

- 3 anúncios de 30–60 s: gancho + problema + mecanismo + CTA.
- 3–5 reels de 15–30 s: uma ideia forte cada (um mito, um número, uma história).
- Marque no roteiro os trechos que funcionam sozinhos (`[CORTE-1]`, `[CORTE-2]`).

## 5. Limites

- Escassez, bônus, preço "de/por" e garantia só se forem verdadeiros.
- Nada de renda prometida, cura, resultado garantido; segmentos regulados com revisão.

## 6. Portão de saída

```
[ ] Estrutura completa, tempos somam a duração-alvo (palavras ÷ 150 = min)
[ ] Cada parágrafo com marcação de tela
[ ] Objeções respondidas; um CTA claro repetido no fim
[ ] Cortes derivados marcados
[ ] Escassez, garantia, preço e provas reais
```
