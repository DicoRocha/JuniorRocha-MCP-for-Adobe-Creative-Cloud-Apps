# roteiro-carrossel — funil de deslize

A execução é `social-carrossel`. Base: `docs/conhecimento/06` e `10`.

## 1. Antes

Do briefing (`plan-briefing`): público, nível de consciência, mensagem única, CTA. Defina:
- **Promessa da capa** (o que a pessoa ganha deslizando).
- **Tipo:** lista ("5 sinais…"), passo a passo, mito × verdade, antes/durante/depois, história, comparação.
- **Número de slides:** 5–10 (abaixo de 5 rende menos; acima de 10 perde gente).

## 2. Estrutura

| Slide | Função | Texto |
|---|---|---|
| 1 · Capa | Para o dedo; funciona sozinha no feed | Título 3–8 palavras + subtítulo opcional; sem logo grande |
| 2 · Contexto | Problema ou por que importa; sinal de continuação ("→") | 1–2 frases |
| 3…N−2 · Ideias | **Uma ideia por slide**, numeradas, mesmo layout | Título curto + até 30 palavras |
| N−1 · Resumo/prova | Juntar tudo, ou prova real (número, caso autorizado) | Lista curta |
| N · CTA | Uma ação: salvar, comentar, agendar, link | Verbo + resultado |

Regra de leitura: cada slide entende-se em **3 s**. Se precisa de mais, divida.

## 3. Continuidade visual (puxa o deslize)

Escolha uma:
- Elemento que **atravessa a borda** entre slides (linha, forma, foto panorâmica dividida).
- Número grande do passo no mesmo canto.
- Barra de progresso fina na base.

## 4. Ganchos de capa (escolha um e escreva 3 variações)

Lista com número ("3 coisas que…") · pergunta direta · erro comum ("Você faz isso errado") ·
antes × depois (onde permitido) · promessa específica com prazo ("em 10 minutos").

## 5. Entrega (arquivo `00_briefing/roteiro-carrossel.md`)

```markdown
# Carrossel · <tema> · <n> slides · <proporção>
Continuidade: <regra>
| # | Função | Título | Texto | Imagem/insumo | Nota de design |
Variações de capa: 1) … 2) … 3) …
CTA: …
```

## 6. Erros comuns

- Capa que só funciona com o slide 2 ("Continua…").
- Slide com três ideias.
- CTA diferente em cada slide.
- Prova inventada no slide de prova; antes/depois em segmento que veda.
- Texto do slide maior que ~40 palavras.

## 7. Portão

```
[ ] Capa funciona sozinha; 3 variações de gancho
[ ] Uma ideia por slide; ≤ 40 palavras por slide
[ ] Regra de continuidade escolhida
[ ] Um CTA no último slide
[ ] Fatos e provas reais
```
