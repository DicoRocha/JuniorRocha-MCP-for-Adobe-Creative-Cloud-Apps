# qa-anti-generico — ter um ponto de vista

Complementa `qa-revisao-visual` (técnico). Esta skill pergunta: **alguém reconheceria esta peça
como desta marca, desta campanha?**

## 1. Texto — sinais de genérico

| Sinal | Exemplo | Troca |
|---|---|---|
| Adjetivo vazio | "incrível", "inovador", "de excelência", "transforme sua vida" | Fato concreto ou benefício específico |
| Promessa vaga | "o melhor para você" | Quem, o quê, quando |
| Estrutura de IA | "Não é só X, é Y." · "Descubra o poder de…" · tríade de adjetivos | Frase direta, voz da marca |
| Excesso de pontuação | travessões em toda frase, emoji em toda linha, "!" | Ritmo variado, uma ênfase |
| CTA genérico | "Saiba mais" | Verbo + resultado ("Agende sua avaliação") |
| Idioma de tradução | calcos do inglês | Escrever no idioma do público, como ele fala |

Teste: troque o nome da marca por um concorrente. Se o texto continua servindo, é genérico.

## 2. Visual — sinais de template

| Sinal | Troca |
|---|---|
| Tudo centralizado e do mesmo tamanho | Assimetria com hierarquia (`craft-composicao`) |
| Degradê roxo-azul padrão, glassmorphism sem motivo | Paleta do kit, uma cor de destaque |
| Foto de banco óbvia (aperto de mão, sorriso perfeito para a câmera) | Foto real do cliente ou dirigida (`docs/conhecimento/09` para IA) |
| Ícones genéricos de linha em toda parte | Menos ícones; desenho próprio; ou nenhum |
| Ornamento sem função (formas soltas, partículas) | Elemento que carrega a ideia (o anel do selo, o arco do alinhador) |
| Mesmas margens de 20 px "do app" | Escala de espaçamento da peça |
| Animação: tudo entra com fade no mesmo tempo | Direção de motion com herói (`motion-direcao-de-arte`) |

## 3. Procedimento

1. Escreva em uma linha a **ideia** da peça (ex. "decisão sem pressa").
2. Liste o que na peça **carrega** essa ideia (foto calma, ritmo lento, tipo serifado, muito respiro).
3. Marque tudo que não carrega nada → remova ou substitua.
4. Reescreva o texto com o teste do concorrente.
5. Olhe de novo (prévia do app) e compare com a versão anterior.

## 4. Erros comuns

- "Enfeitar" para parecer premium (premium é contenção).
- Copiar a estrutura da referência inteira em vez do princípio.
- Três variações que são a mesma peça com outra cor.

## 5. Portão

```
[ ] Ideia da peça escrita em uma linha
[ ] Texto passa no teste do concorrente
[ ] Nenhum ornamento sem função
[ ] Hierarquia assimétrica e intencional
[ ] Variações realmente diferentes (conceito, não cor)
```
