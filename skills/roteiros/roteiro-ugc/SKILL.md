# roteiro-ugc — natural, mas planejado

Base: `docs/conhecimento/10` §3. Depois: `video-ugc`.

## 1. Formatos

| Formato | Estrutura (15–45 s) |
|---|---|
| **Review** | gancho com opinião → contexto ("eu tinha X") → uso real → resultado → recomendação |
| **Unboxing** | gancho ("chegou!") → abrir → 3 detalhes em close → primeira impressão → CTA |
| **Tutorial** | resultado primeiro → passos 1-2-3 em close → dica extra → CTA |
| **3 motivos** | "3 motivos para…" → motivo 1, 2, 3 (um plano cada) → o melhor por último → CTA |
| **Antes e depois** | só onde é permitido; o "antes" curto, o "depois" com tempo de tela |
| **Dia a dia** | situação real → produto aparece resolvendo → reação → CTA |

## 2. Gancho falado (0–3 s)

Frase na primeira pessoa, olhando para a lente, com o produto no quadro:
"Eu não acreditava que…", "Isso mudou minha manhã", "Ninguém me falou que…".
Escreva 3 e grave os 3 (o melhor se escolhe na edição).

## 3. Roteiro em tópicos (não texto decorado)

Para cada bloco, **tópicos** que a pessoa fala com as próprias palavras + 1 frase obrigatória
(benefício ou CTA). Texto decorado soa anúncio; tópico soa conversa.

```
Bloco · tempo · tópicos (o que dizer) · frase obrigatória · plano (como filmar)
```

## 4. Planos de celular (cara nativa)

- Vertical 9:16, 4K/30 se possível, luz de janela de frente; microfone de lapela.
- Selfie falando (A-roll) + mãos/produto em close (B-roll) + tela/uso real.
- Movimento leve de mão; nada de tripé perfeito e luz de estúdio (perde a naturalidade).
- Grave cada bloco 2–3 vezes; pausa de 1 s antes e depois de cada fala (facilita o corte).

## 5. Verdade e autorização

- Experiência real da pessoa; nada de depoimento inventado ou ator fingindo ser cliente sem aviso.
- Parceria paga identificada conforme a plataforma. Autorização de uso de imagem por escrito.

## 6. Portão de saída

```
[ ] Formato escolhido; 15–45 s; produto no quadro no gancho
[ ] 3 ganchos falados para gravar
[ ] Roteiro em tópicos com 1 frase obrigatória por bloco
[ ] Lista de planos A-roll / B-roll / tela, vertical
[ ] Experiência real, parceria identificada, autorização de imagem
```
