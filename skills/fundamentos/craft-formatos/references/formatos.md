## Vídeo

| Uso | Formato |
|---|---|
| Reels / TikTok / Shorts | 1080×1920, 30 fps, H.264 ~10–20 Mbps, AAC 48 kHz |
| Feed | 1080×1350 (4:5) |
| YouTube | 1920×1080 (16–24 Mbps) ou 3840×2160 (45–68 Mbps) |
| Master / arquivo | ProRes 422 HQ |
| Com transparência | ProRes 4444 ou sequência PNG |
| Loudness | TikTok/Instagram −10 a −12 LUFS · YouTube −14 LUFS · pico < −1 dBTP |
