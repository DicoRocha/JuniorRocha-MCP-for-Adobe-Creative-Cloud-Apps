# templates/

Brand templates generated by **`jradb_templates_build`** from the brand kit (`00_briefing/kit-de-marca.json`).
Each brand gets a folder `templates/<client>/` with:

| Folder | Files | Use |
|---|---|---|
| `photoshop/` | `post_feed4x5.psdt`, `post_story9x16.psdt`, `post_square1x1.psdt` | Layers Titulo, Apoio, CTA (text), Foto, Logo (smart object), Botao, Fundo: the columns of the `ps_batch_variants` CSV |
| `indesign/` | `flyer_A4.indt`, `catalogo_A4.indt`, `manual_A5.indt` | CMYK swatches and paragraph styles ready to use |
| `illustrator/` | `marca_social.ait` | Social artboards, a swatch group named "Marca", styles Titulo, Corpo and Rotulo |
| `after-effects/` | `lower_third.mogrt`, `titulo.mogrt`, `contador.mogrt`, `templates.aep` | Text fields exposed in Premiere Pro |

`manifest.json` lists the files and the kit they came from; `LEIA-ME.md` explains how to use them. Templates open
as an untitled copy, so the original does not change. Run the tool again when the kit changes. The apps must be
open; building takes a few minutes (use `jradb_code` with `background: true`).

## legendas/ (built-in caption template, not tied to a brand)

| File | Use |
|---|---|
| `Legenda MCP Vertical.mogrt` (1080×1920), `Legenda MCP Horizontal.mogrt` (1920×1080) | Default template for `pr_captions_as_mogrt` when no `.mogrt` is given. Fields: text, text colour, box colour, size (%), box opacity, height (% of the screen), animated entrance. Font: Montserrat SemiBold |
| `legenda_mcp.aep` | Source project in After Effects, to change and export again with `ae_export_mogrt` |
