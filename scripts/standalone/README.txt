Junior Rocha MCP - bridges kit

This zip installs the bridges for After Effects, Illustrator and Lightroom Classic without Node.js.
Photoshop, Premiere Pro and InDesign use the three .ccx files; the server itself is the .mcpb file.

1. Extract the whole zip to a folder.
2. Close After Effects, Illustrator and Lightroom Classic.
3. Windows: double-click INSTALL-BRIDGES.bat
   macOS:   run  chmod +x INSTALL-BRIDGES.command  once, then double-click INSTALL-BRIDGES.command
4. Open the apps again.

What it does
- Copies the folder com.jradbmcp.universal to the CEP extensions folder of your user.
- Switches on the CEP debug mode (PlayerDebugMode) so the apps load a panel that is not signed.
- Copies JrAdbMcpBridge.lrplugin to the Lightroom Classic Modules folder.

To remove: delete those two folders.
